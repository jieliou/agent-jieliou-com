# agent.jieliou.com

Single-page landing site for [personal-agent-kit](https://github.com/jieliou/personal-agent-kit).

## Stack

Pure HTML/CSS/JS. No build system. Deploy to Cloudflare Pages — output directory is the repo root.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
